# Helyi alkalmazásadatok

Ez a könyvtár futásidejű, illetve üzleti adatokat tartalmazhat, ezért az Excel-
és SQLite-fájlokat a repository szándékosan nem verziózza.

Az alkalmazás használatához:

1. másold az adatforrást `otletek_riport.xlsx` néven ebbe a könyvtárba; vagy
2. indítás után töltsd fel az Excel-fájlt az alkalmazás Beállítások oldalán.

A rangsorolási adatbázist a backend első indításkor automatikusan létrehozza
`ranking.sqlite3` néven.
